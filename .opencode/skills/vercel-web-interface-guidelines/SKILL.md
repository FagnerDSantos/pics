# Padrões de Interface e UX
- **Feedback Visual Instantâneo:** Adicione estados de hover, active, focus-visible e skeletons para carregamentos.
- **Microinterações:** Utilize transições sutis (150-300ms) com easings naturais.
- **Acessibilidade:** Navegação total por teclado, contraste adequado (WCAG AA), suporte a Screen Readers e aria-labels.
- **Tipografia e Espaçamento:** Mantenha hierarquia clara utilizando unidades consistentes (`rem`, `gap`, `padding`).
